# Echo of Me

A 2D puzzle platformer built in Godot 4.5, developed as a student project for NTNU's IMT3603 course.

## Concept

Players record their own movements and actions, then spawn "Echoes" that replay those recordings exactly. By coordinating with past versions of themselves, players solve puzzles involving pressure plates, doors, moving platforms, and environmental hazards — set in a dark, ancestral cave.

## Features

- Action recording and echo playback system
- Progressive powerup unlocks (sprint, double jump, wall climb, dash)
- Physics-based box interactions (push, carry, throw)
- Multiple hand-crafted puzzle levels with increasing complexity

## Running the Project

Open the `echo-of-me/` folder in the Godot editor and run the project from there.
